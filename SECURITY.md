# Security policy

## Supported versions

Security fixes go into the latest release. Version 0.2.0 and later are supported; 0.1.x is not.

## Reporting a vulnerability

Please report vulnerabilities privately rather than in a public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/Zakhele-TechWannabe/respectscraper/security/advisories/new), or
- email gamedevoxzakhele@gmail.com with "RespectScraper security" in the subject.

Include the version, a description, and steps to reproduce. You will get an acknowledgement within a week.

Reports are especially welcome for any way RespectScraper can be made to fetch a URL that robots.txt disallows, or to read past its size limits.
